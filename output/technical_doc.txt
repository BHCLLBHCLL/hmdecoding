7. BINARY FORMAT NOTES
----------------------------------------
The .hm format is a proprietary binary format developed by Altair
Engineering. Key observations from this file:

  - File is gzip compressed (header at byte offset ~12)
  - Decompressed data contains binary arrays
  - Section markers identified (0x0000007e pattern)
  - Node data stored as coordinate triples
  - Element data stored with connectivity information
  - No public specification available

8. PARSING STRATEGY
----------------------------------------
The parser uses pattern recognition to extract data:
  1. Decompress gzip data
  2. Scan for coordinate patterns (id,x,y,z as doubles)
  3. Scan for element connectivity patterns
  4. Identify component boundaries

9. RECOMMENDED TOOLS
