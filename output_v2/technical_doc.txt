7. BINARY FORMAT ANALYSIS
----------------------------------------
The .hm format is a proprietary binary format developed by Altair
Engineering. Key observations:

  - File uses gzip compression
  - Binary data contains mixed integer and floating-point arrays
  - No public specification or open-source parser available
  - Format may vary between HyperMesh versions

8. PARSING LIMITATIONS
----------------------------------------
This parser uses heuristic pattern matching which may:
  - Miss nodes/elements that don't match expected patterns
  - Extract false positives from binary data
  - Not preserve original element IDs or component assignments
  - Not extract all geometry information

For accurate parsing, use Altair HyperMesh or export to
standard formats (Nastran, Abaqus, IGES, STEP).
